# Portfolio - Krzysztof Tomecki

Portfolio UX/UI / Product Design built with Next.js, React and TypeScript.

## Project

The app lives in the `porfolio` directory.

Main routes:

- `/` - portfolio home
- `/portfolio` - redirects to the portfolio home
- `/fabb` - Fabb case study
- `/propoint` - Propoint case study

## Run locally

```powershell
cd porfolio
npm install
npm run dev
```

Open:

```text
http://localhost:3001
```
